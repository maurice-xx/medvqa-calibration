# 论文框架 v2：Format-Bound Calibration（四层结构）

> 标题（主）：**Format-Bound Calibration: Answer Format and Scoring Context Both Break Confidence Transfer in Medical VQA**
> 备选：The Format Tax（宣传/arXiv 用）
> 目标：NLPCC / PRICAI / ICPR（CCF-C）
> 版本：v2（2026-11-03）。相对 v1 的变化：主线从"迁移矩阵"改为"**生成/评分解耦 + 阈值失效**"；新增 A′ 与选择性风险；补充竞争文献。

---

## 0. 一句话论点

> 在生成式医学 VQA 中，置信度读数同时被**生成协议**（怎么作答）和**评分协议**（在哪段前缀下读概率）塑造，两者贡献相当（各约 0.2 的绝对置信度跨度）；因此**在一个协议上校准好的置信度，换协议后既不可比也不可迁移**——按 A 格式 5% 风险设定的分诊阈值，套到 B 格式后实际风险 53.8%。逐格式独立校准是唯一稳健解，格式条件化共享参数没有收益。

## 2. 摘要骨架（~190 词，五句）

1. 临床部署要求置信度可信，医学 VLM 的校准已被系统研究。
2. 但校准读数依赖两个很少被同时控制的协议：**生成格式**与**评分上下文**。
3. 我们在 3 个数据集、3 个模型、432 题上做 3×3 反事实重评分（固定答案、只换前缀）：评分与生成效应量级相当（0.21 vs 0.20；0.23 vs 0.26），且各格式只在"自己的前缀"下校准最好（HealthGPT B：0.061 vs 0.160）。
4. 后果是决策层面的：A 格式 5% 风险阈值套到 B 格式，实际风险 53.8%（11 倍），覆盖 63.7%。
5. 逐格式校准可把 ECE 降到 0.03–0.09；格式条件化共享参数不优于独立拟合——协议特异性无法被参数共享吸收。

## 4. Related Work（1 页，5 小节，每节 3–4 句 + 差异句）

1. **医学 VQA 校准**：2604.02543（过度自信 + HAC）、2606.27023（训练式）、CARE（GRPO + 置信度奖励）、MVC-Bench（分类）。
   → 差异：均默认单一模板；本文化格式为**测量变量**。
2. **协议敏感性**：2605.27752（条件上下文翻转 ECE 符号）、Qualification by Calibration（只改置信度报告方式；结论"温和提示几乎不动校准"）。
   → 差异：它任务近饱和（acc≈0.98）；我们 acc 0.45–0.76，效应出现；且我们同时控生成与评分两轴。
3. **格式不确定性**：MCQ 校准的 answer/format uncertainty 分解。
   → 借用其机制解释；本文给出生成端的实证与量化。
4. **多格式信号**：Multi-Format Agreement（表格 QA 用输入格式一致性估置信度）。
   → 它用格式**改善**置信度；我们证明输出格式**破坏**可比性——方向互补。
5. **推理提示**：CoT 默认"先推理更好"。
   → 反例：医学模型 B 格式准确率 −31pp（标签 5pp + 观察 26pp）。

## 5. Protocol（1.5 页）

### 5.1 数据（E1–E3）
- SLAKE test+validate 432 题 / 173 图（seed 20261022，图像 md5 半区）
- VQA-RAD 150 题 / 116 图
- VQA-Med2019 250 题 / 250 图（plane 125 + modality 125；说明为何排除 abnormality/organ）
- 图像不相交、同图不跨 fit/test

### 5.2 三种回答格式（生成协议）
- A 直接短答；B 观察一句 + `Answer:`；C 短答 + 自报 `Confidence: 0-100`
- **A′ 控制**（仅标签，无观察，无自报）用于分解标签与观察

### 5.3 三种评分上下文（3×3 的列）
- 统一中性指令 `Answer the question based on the image.`，只变答案前缀：
  - sA：`\n\n`
  - sB：`\n\nObservation: The image shows a medical scan.\nAnswer: `
  - sC：`\n\nAnswer: `
- **明确声明**：sB 使用固定中性观察，因为外来答案没有自己的观察；因此对角是"前缀匹配"而非"完全复现"（对角相关 0.42/0.43，写入 Limitations）
- 自回归模型中后缀不影响答案 token 概率 → 评分上下文严格等价于**前缀**

### 5.4 模型与置信度
- Qwen3-VL-8B、HealthGPT-Pro-8B、Gemma-4-E4B；greedy、max_pixels 448²、offline
- 信号：span token 几何均值（主）、首 token（辅）、自报（仅 C）

### 5.5 指标与统计
- acc / ECE(10-bin) / Brier / AUROC / 合规率 / 选择性风险
- **效应定义**：评分效应 = 同答案换前缀的置信度跨度；生成效应 = 同前缀换答案的跨度
- 图像聚类 bootstrap 1000 次；GEE logistic（cluster=image）
- 校准器：power scaling（`c^(1/T)`，**不称 temperature scaling**）、logistic、isotonic
- 预注册 v2 冻结，test 标签未用于调参

## 6. Results（3 页，5 小节）

### 6.1 格式改变一切，强度随模型分层（L1）
**T2**：三模型 × 三格式（acc/conf/ECE/Brier/AUROC/合规率）
- HealthGPT：0.755/0.729/**0.052** → 0.447/0.791/**0.352** → 0.660/0.772/0.128
- Qwen：0.521/0.783/0.263 → 0.472/0.949/0.477 → 0.521/0.957/0.436
- Gemma：0.498/0.853/0.358 → 0.498/0.884/0.386 → 0.488/0.875/0.387（**平坦**）
- 外部：VQA-RAD、VQA-Med 同向（VQA-Med 上 Qwen 的 B 效应减弱，如实报告异质性）
**F2**（ECE 柱状 + CI）

### 6.2 机制：生成与评分各占一半（L2，**主表 T3**）
**T3**：3×3 矩阵（三模型），两行汇总：
| 模型 | 评分效应 | 生成效应 | 对角 ECE A/B/C | 统一 A 上下文 A/B/C |
|---|---|---|---|---|
| Qwen | 0.210 | 0.198 | 0.385/0.147/0.169 | 0.385/0.249/0.270 |
| HealthGPT | 0.228 | 0.262 | 0.089/0.061/0.113 | 0.089/0.160/0.103 |
| Gemma | 0.017 | 0.037 | 0.494/0.469/0.467 | 0.494/0.490/0.486 |
**关键句**：每个格式只在"自己的前缀"下校准最好；换前缀后排序翻转（HealthGPT B 0.061→0.160）。
**F3**（热图：两种评分上下文下的 ECE 对比）

### 6.3 后果：阈值跨协议失效（L3）
**T4**：A 上 5% 风险阈值（0.751）套到三格式
- A：覆盖 49.1%、风险 4.7% ✓
- B：覆盖 63.7%、风险 **53.8%**（11 倍）
- C：覆盖 65.5%、风险 15.9%
- 另报 high-confidence error rate @0.8/0.9 与 coverage@10% risk
**F5**（risk-coverage 曲线）

### 6.4 A′ 分解与措辞鲁棒性（L2 补充 / L1 稳健性）
- A′：HealthGPT 0.755→0.706（标签 −5pp）→0.447（观察 −26pp）；Qwen 标签 0、观察 −5pp；Gemma 均 ~0
- 措辞：三变体下格式排序不变（HG 恒 A<C<B），幅度敏感（B acc 0.447–0.620）——"格式类别定方向，措辞调幅度"

### 6.5 修复：每协议校准；条件化无免费午餐（L4）
**T5**：raw / global / independent / format-conditioned
- Qwen 0.274/0.488/0.436 → global 0.067 → cond 0.033 ≈ indep 0.032
- HealthGPT 0.057/0.362/0.135 → global 0.058 → cond = indep 0.087
- Gemma：global 0.073 最好
- few-shot：每格式 50–100 样本可恢复；条件化在 10–100 样本区间无优势
**F6**（few-shot 曲线）

## 7. Discussion（0.75 页，3 段）

1. **为什么会这样**：置信度是"模型×协议"的测量；生成改变答案与正确性，评分改变同一答案的读数；借 answer/format uncertainty 解释 B 格式为何既降准确率又抬置信度。
2. **与"提示鲁棒"文献的张力**：Qualification 在 acc≈0.98 的任务上看到鲁棒；我们 acc 0.45–0.76 看到剧烈效应 → **敏感性是"任务未饱和 + 模型够强"的函数**（Gemma-4B 免疫正好佐证）。
3. **部署含义**：换输出接口必须重新校准；阈值不能跨接口复用；合规率应作为上线 gate。

## 8. Limitations（0.5 页，六条）

1. 432 题是 SLAKE 过滤上限；VQA-Med 仅知觉题
2. 正确性依赖别名归一化，开放题有噪声；VQA-Med modality 映射手工
3. 对角重评分仅"前缀匹配"（ρ=0.42/0.43），非严格复现生成
4. sB 用固定中性观察，外来答案无自身观察
5. 单轮、无多图、无人类评估
6. Gemma-4B 的"免疫"可能来自能力不足而非稳健（无法区分）
