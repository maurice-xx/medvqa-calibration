## 二、缝隙判定

**未被占据的位置：生成式医学 VQA 中，跨回答条件（answer format / output constraint）的校准器迁移。**

具体而言：同一模型、同一图像、同一问题，在"直接短答 / 结构化 JSON / 附带理由再答"等条件下分别提取置信度（token 概率 + 自报），问：
1. 同一模型在不同格式下的校准误差是否系统性不同？（现象存在性——大概率存在，两篇论文的旁证都很强）
2. 在格式 A 上拟合的校准器（temperature/Platt），搬到格式 B 是否失效？（核心缺口，没人做过生成式 MedVQA 版）
3. 便宜的修复：每个格式一个标量参数的 format-aware temperature scaling 能否用极小验证集恢复校准？（自己的增量贡献）

## 三、与四篇的区分度（审稿人问"你和 X 有什么不同"时的答案）

- vs 2604.02543：他们比较提示策略并分别校准；我们研究**校准器跨条件迁移**与修复——变量不同（他们：跨数据集；我们：跨格式）
- vs 2605.27752：他们是纯文本诊断；我们是医学多模态 + 校准器层面 + 修复
- vs MVC-Bench：他们是 CLIP 式分类；我们是生成式 VQA（token 级置信度读出是分类模型不存在的对象）
- vs 2606.27023：他们训练修复；我们零训练、部署侧（临床更现实：没人愿意为每种格式微调一次）

## 四、CCF-C 可行性评估

- 定位：系统性实证 + 简单有效修复（format-aware scaling），符合 NLPCC/PRICAI/ICPR 的录用画像
- 自有资产复用：SLAKE 管线、三模型推理框架、答案归一化/解析、聚类 bootstrap——上个月 credmed_vqa 的基建直接迁移
- 规模：pilot 100 题（半天）→ 500–1000 题（1–2 天 GPU）→ VQA-RAD 外部验证
- 风险：主结果若"迁移其实可行"（τ 高），故事变弱——需预设 kill criteria；但即便如此，"医学 VQA 校准对格式稳健"也是与 MVC-Bench 域迁移失败相反的可报告发现

## 五、最小实验（pilot，1 天）

- SLAKE validate 抽 100 题（英文闭式，复用筛题脚本，换 seed）
- 模型 2 个：Qwen3-VL-8B（锚点）+ HealthGPT-Pro-8B（医学）
- 条件 3×：A 直接短答 / B JSON 结构化 / C 短理由+答案
- 置信度 2×：答案 token 概率（几何均值+首 token）+ 自报 0–100
- 指标：ECE（10 bin + ACE）、Brier、AUROC（错误检测）、置信度分布
- 迁移矩阵：3×3 格式 × 校准器（在 A 拟合 → 测 B/C…），对角线 vs 非对角线之差即"迁移代价"
- kill criteria：若三种格式间 ECE 差 < 1pp 且迁移代价可忽略 → 现象不存在，止损
